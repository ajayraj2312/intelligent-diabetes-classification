How the archerfish search works

Implementation of the AFO wrapper used in this project

Documented assumptions
01

Encode the school

Each of {{ afo.n_archers }} archers holds a continuous vector in [0,1]8. Thresholding at 0.5 decodes it into a feature mask, constrained to 2–7 features.

02

Correct the aim

An archer shoots toward the prey (best subset) with a refraction-style correction that is more precise when its fitness is close to the leader's.

03

Compete & disperse

A peer-competition term points some shots at school-mates, and jet dispersion cools over iterations to shift from exploration to exploitation.

04

Retain the best

Greedy retention accepts only improving positions. Fitness combines cross-validated F1 and AUC with a parsimony penalty.

Subset quality Q(S) = 0.5 · F1cv(S) + 0.5 · AUCcv(S)

Balances thresholded precision/recall with threshold-free ranking quality.

Objective (minimise) J(S) = (1−α) · (1 − Q(S)) + α · |S| / d

α = {{ afo.alpha }}; the second term rewards smaller feature subsets.

{{ icon('info', 16) }}

Implementation note: the project report describes Archerfish Optimization conceptually but does not publish its exact equations. This prototype therefore implements a transparent Archerfish-inspired population metaheuristic with the phases above. The surrogate (random forest, 80 trees) makes the wrapper affordable, the imputer and scaler are fitted inside each cross-validation fold to avoid leakage, and every run is seeded for reproducibility. No random or hand-picked subset is relabelled as AFO.
